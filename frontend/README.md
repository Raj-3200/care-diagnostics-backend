# Care Diagnostics LIMS Frontend

Next.js frontend for the Care Diagnostics laboratory management system.

## Quick Start
1. Clone repo.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_URL`.
4. Run `npm run dev`.

## Vercel Deployment
- Framework: Next.js
- Build Command: `npm run build`
- Required env vars: `NEXT_PUBLIC_API_URL`
- Set `NEXT_PUBLIC_API_URL` to your Render backend URL ending in `/api/v1`.
